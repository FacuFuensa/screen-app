# Screen v1 — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App iOS para dos adultos que se limitan el tiempo en pantalla mutuamente: cada uno bloquea sus apps; para minutos extra o para aflojar un límite le pide aprobación al otro, que responde desde su celular.

**Architecture:** Todo el bloqueo ocurre en el dispositivo (FamilyControls + ManagedSettings + DeviceActivity, con 3 extensiones que comparten estado por App Group). **Tech Stack:** SwiftUI (iOS 17.4+, modo Swift 5), XcodeGen, supabase-swift 2.55.1, Supabase (Postgres + RLS + pgTAP + Edge Functions en Deno), jose 6.2.12, supabase-js 2.117.3, GitHub Actions.

/// A daily time range during which a group is blocked, in minutes of the day.
/// `endMinute` is exclusive; when it is lower than `startMinute` the window
/// wraps past midnight (23:00 → 07:00).
public struct BlockWindow: Codable, Equatable, Hashable, Sendable {
    public static let minutesPerDay = 1440
    /// DeviceActivitySchedule rejects intervals shorter than this.
    public static let minimumSegment = 15

    public var startMinute: Int
    public var endMinute: Int

    public init(startMinute: Int, endMinute: Int) {
        self.startMinute = startMinute
        self.endMinute = endMinute
    }

    public var length: Int {
        startMinute < endMinute ? endMinute - startMinute : Self.minutesPerDay - startMinute + endMinute
    }

    public var isValid: Bool {
        let range = 0..<Self.minutesPerDay
        guard range.contains(startMinute), range.contains(endMinute), startMinute != endMinute else { return false }
        return segments().allSatisfy { $0.length >= Self.minimumSegment }
    }

    public func contains(minute m: Int) -> Bool {
        startMinute < endMinute ? (m >= startMinute && m < endMinute) : (m >= startMinute || m < endMinute)
    }

    /// True when every minute blocked by `other` is also blocked by `self`.
    public func covers(_ other: BlockWindow) -> Bool {
        (0..<Self.minutesPerDay).allSatisfy { !other.contains(minute: $0) || contains(minute: $0) }
    }

    /// Same-day pieces for DeviceActivitySchedule, which cannot cross midnight.
    /// The evening piece of a wrapping window ends at 23:59 and is flagged so the
    /// monitor keeps the shield up until the morning piece starts at 00:00.
    public func segments() -> [DaySegment] {
        if startMinute < endMinute {
            return [DaySegment(startMinute: startMinute, endMinute: endMinute, continuesNextDay: false)]
        }
        if endMinute == 0 {
            return [DaySegment(startMinute: startMinute, endMinute: 1439, continuesNextDay: false)]
        }
        return [
            DaySegment(startMinute: startMinute, endMinute: 1439, continuesNextDay: true),
            DaySegment(startMinute: 0, endMinute: endMinute, continuesNextDay: false),
        ]
    }
}

public struct DaySegment: Equatable, Sendable {
    public let startMinute: Int
    public let endMinute: Int
    public let continuesNextDay: Bool

    public init(startMinute: Int, endMinute: Int, continuesNextDay: Bool) {
        self.startMinute = startMinute
        self.endMinute = endMinute
        self.continuesNextDay = continuesNextDay
    }

    public var length: Int { endMinute - startMinute }
}
```

/// The part of a group that decides how strict it is. `appKeys` are stable
/// string forms of the opaque Screen Time tokens (see `FamilyActivitySelection.appKeys`).
public struct LimitConfig: Codable, Equatable, Sendable {
    public var dailyMinutes: Int?
    public var window: BlockWindow?
    public var appKeys: Set<String>

    public init(dailyMinutes: Int?, window: BlockWindow?, appKeys: Set<String>) {
        self.dailyMinutes = dailyMinutes
        self.window = window
        self.appKeys = appKeys
    }
}

public enum ChangeVerdict: Equatable, Sendable {
    case unchanged, tightening, loosening
}

/// Tightening applies at once; anything that frees time in any way needs the
/// partner's approval. A change that tightens one thing and loosens another
/// is a loosening.
public enum LimitChange {
    public static func classify(from old: LimitConfig, to new: LimitConfig) -> ChangeVerdict {
        if old == new { return .unchanged }
        return isLoosening(from: old, to: new) ? .loosening : .tightening
    }

    public static func removesApps(from old: LimitConfig, to new: LimitConfig) -> Bool {
        !old.appKeys.isSubset(of: new.appKeys)
    }

    static func isLoosening(from old: LimitConfig, to new: LimitConfig) -> Bool {
        if removesApps(from: old, to: new) { return true }
        if let o = old.dailyMinutes {
            guard let n = new.dailyMinutes, n <= o else { return true }
        }
        if let o = old.window {
            guard let n = new.window, n.covers(o) else { return true }
        }
        return false
    }
}
```

/// Per-device state for the current day, shared by the app and its extensions.
public struct DayLedger: Codable, Equatable, Sendable {
    public static let appliedCap = 200

    public private(set) var day: String
    public private(set) var wildcardUsed: Bool
    /// Granted request IDs already turned into credit; survives day changes so a
    /// late sync never applies the same grant twice.
    public private(set) var appliedRequestIDs: [String]
    public var runtime: [String: GroupRuntime]

    public init(day: String) {
        self.day = day
        self.wildcardUsed = false
        self.appliedRequestIDs = []
        self.runtime = [:]
    }

    /// Midnight: daily limits and credits reset; schedule state is left to the
    /// window activities, which know whether a window spans midnight.
    public mutating func roll(to newDay: String) {
        guard newDay != day else { return }
        day = newDay
        wildcardUsed = false
        for key in runtime.keys {
            runtime[key]?.limitReached = false
            runtime[key]?.creditActive = false
        }
    }

    public var canUseWildcard: Bool { !wildcardUsed }

    @discardableResult
    public mutating func consumeWildcard() -> Bool {
        guard !wildcardUsed else { return false }
        wildcardUsed = true
        return true
    }

    public func hasApplied(_ id: String) -> Bool { appliedRequestIDs.contains(id) }

    public mutating func markApplied(_ id: String) {
        guard !hasApplied(id) else { return }
        appliedRequestIDs.append(id)
        if appliedRequestIDs.count > Self.appliedCap {
            appliedRequestIDs.removeFirst(appliedRequestIDs.count - Self.appliedCap)
        }
    }
}

create table public.profiles (
  id uuid primary key references auth.users(id) on delete cascade,
  display_name text not null check (char_length(display_name) between 1 and 40),
  apns_token text,
  last_seen_at timestamptz,

);

create function public.ensure_profile(p_name text) returns public.profiles
language plpgsql security definer set search_path = public as $$
declare r public.profiles;
begin
  if auth.uid() is null then raise exception 'not_authenticated'; end if;
  insert into profiles (id, display_name) values (auth.uid(), trim(p_name))
  on conflict (id) do update set display_name = excluded.display_name
  returning * into r;
  return r;
end $$;

create function public.create_invite() returns text
language plpgsql security definer set search_path = public as $$
declare code text;
begin
  if auth.uid() is null then raise exception 'not_authenticated'; end if;
  if public.my_pair_id() is not null then raise exception 'already_paired'; end if;
  delete from pairs where user_a = auth.uid() and user_b is null;
  loop
    code := lpad(floor(random() * 1000000)::int::text, 6, '0');
    begin
      insert into pairs (user_a, invite_code) values (auth.uid(), code);
      return code;
    exception when unique_violation then
      -- code collision: try another one
    end;
  end loop;
end $$;

create function public.join_pair(p_code text) returns uuid
language plpgsql security definer set search_path = public as $$
declare p public.pairs;
begin
  if auth.uid() is null then raise exception 'not_authenticated'; end if;
  if public.my_pair_id() is not null then raise exception 'already_paired'; end if;
  select * into p from pairs where invite_code = trim(p_code) and user_b is null for update;
  if not found then raise exception 'invalid_code'; end if;
  if p.user_a = auth.uid() then raise exception 'own_code'; end if;
  delete from pairs where user_a = auth.uid() and user_b is null;
  update pairs set user_b = auth.uid() where id = p.id;
  return p.id;
end $$;

-- Each side keeps its local limits; requests and events go with the pair.
create function public.leave_pair() returns void
language plpgsql security definer set search_path = public as $$
begin
  delete from pairs where id = public.my_pair_id();
end $$;

create function public.heartbeat(p_auth_status text, p_apns_token text default null) returns uuid
language plpgsql security definer set search_path = public as $$
declare prev text; pid uuid := public.my_pair_id(); eid uuid;
begin
  select auth_status into prev from profiles where id = auth.uid() for update;
  if not found then raise exception 'no_profile'; end if;
  update profiles
     set last_seen_at = now(), auth_status = p_auth_status,
         apns_token = coalesce(p_apns_token, apns_token), silent_alerted_at = null
   where id = auth.uid();

    insert into events (pair_id, actor, kind) values (pid, auth.uid(), 'auth_revoked')
    returning id into eid;
  end if;
  return eid;
end $$;

create function public.window_contains(p_start int, p_end int, p_minute int) returns boolean
language sql immutable as $$
  select case when p_start < p_end then p_minute >= p_start and p_minute < p_end
              else p_minute >= p_start or p_minute < p_end end
$$;

create function public.window_covers(n_start int, n_end int, o_start int, o_end int) returns boolean
language sql immutable as $$
  select case
    when o_start is null then true
    when n_start is null then false
    else not exists (
      select 1 from generate_series(0, 1439) m
       where public.window_contains(o_start, o_end, m)
         and not public.window_contains(n_start, n_end, m))
  end
$$;

create function public.is_loosening(
  o_min int, n_min int, o_ws int, o_we int, n_ws int, n_we int, p_removes_apps boolean
) returns boolean language sql immutable as $$
  select coalesce(p_removes_apps, false)
      or (o_min is not null and (n_min is null or n_min > o_min))
      or not public.window_covers(n_ws, n_we, o_ws, o_we)
$$;

create function public.save_group(

) returns text

begin

  select * into g from limit_groups where id = p_id for update;
  if not found then
    select count(*) into n from limit_groups where owner = auth.uid();
    if n >= 5 then raise exception 'too_many_groups'; end if;
    insert into limit_groups (id, owner, name, app_count, daily_minutes, window_start, window_end)
    values (p_id, auth.uid(), trim(p_name), p_app_count, p_daily_minutes, p_window_start, p_window_end);

      insert into events (pair_id, actor, kind, group_id) values (pid, auth.uid(), 'group_created', p_id);
    end if;
    return 'created';

       p_app_count < g.app_count

create function public.request_extra_time(p_group_id uuid, p_minutes int, p_message text default null)
returns uuid language plpgsql security definer set search_path = public as $$
declare pid uuid := public.my_pair_id(); rid uuid;
begin
  if pid is null then raise exception 'not_paired'; end if;
  if not exists (select 1 from limit_groups where id = p_group_id and owner = auth.uid()) then
    raise exception 'not_owner';
  end if;
  if p_minutes is null or p_minutes not in (5, 15, 30) then raise exception 'invalid_minutes'; end if;
  update requests set status = 'superseded'
   where group_id = p_group_id and kind = 'extra_time' and status = 'pending';
  insert into requests (pair_id, from_user, kind, group_id, minutes, message)
  values (pid, auth.uid(), 'extra_time', p_group_id, p_minutes, nullif(trim(p_message), ''))
  returning id into rid;
  return rid;
end $$;

create function public.request_loosen(p_group_id uuid, p_payload jsonb, p_message text default null)
returns uuid language plpgsql security definer set search_path = public as $$
declare pid uuid := public.my_pair_id(); rid uuid;
begin
  if pid is null then raise exception 'not_paired'; end if;
  if not exists (select 1 from limit_groups where id = p_group_id and owner = auth.uid()) then
    raise exception 'not_owner';
  end if;
  if jsonb_typeof(p_payload) is distinct from 'object' then raise exception 'invalid_payload'; end if;
  if not coalesce((p_payload->>'delete')::boolean, false)
     and not (p_payload ?& array['name', 'app_count', 'daily_minutes', 'window_start', 'window_end']) then
    raise exception 'invalid_payload';
  end if;
  update requests set status = 'superseded'
   where group_id = p_group_id and kind = 'loosen_limit' and status = 'pending';
  insert into requests (pair_id, from_user, kind, group_id, payload, message)
  values (pid, auth.uid(), 'loosen_limit', p_group_id, p_payload, nullif(trim(p_message), ''))
  returning id into rid;
  return rid;
end $$;

create function public.answer_request(p_request_id uuid, p_grant boolean, p_minutes int default null)
returns public.requests language plpgsql security definer set search_path = public as $$
declare r public.requests; pid uuid := public.my_pair_id(); p jsonb; del boolean := false;
begin
  select * into r from requests where id = p_request_id for update;
  if not found or r.pair_id is distinct from pid then raise exception 'not_found'; end if;
  if r.from_user = auth.uid() then raise exception 'cannot_answer_own'; end if;
  if r.status <> 'pending' then raise exception 'not_pending'; end if;
  if now() >= r.expires_at then raise exception 'request_expired'; end if;
  if p_grant and r.kind = 'extra_time' and p_minutes is not null and (p_minutes < 1 or p_minutes > 120) then
    raise exception 'invalid_minutes';
  end if;

  if p_grant and r.kind = 'loosen_limit' then
    p := r.payload;
    del := coalesce((p->>'delete')::boolean, false);
    if not del then
      update limit_groups
         set name = p->>'name', app_count = (p->>'app_count')::int,
             daily_minutes = (p->>'daily_minutes')::int,
             window_start = (p->>'window_start')::int, window_end = (p->>'window_end')::int,
             updated_at = now()
       where id = r.group_id;
    end if;
  end if;

  update requests
     set status = case when p_grant then 'granted' else 'denied' end,
         granted_minutes = case when p_grant and r.kind = 'extra_time' then coalesce(p_minutes, r.minutes) end,
         answered_at = now()
   where id = r.id
  returning * into r;

  insert into events (pair_id, actor, kind, group_id, data)
  values (pid, auth.uid(), case when p_grant then 'request_granted' else 'request_denied' end, r.group_id,
          jsonb_build_object('request_id', r.id, 'request_kind', r.kind, 'minutes', r.granted_minutes));

  -- Last, so the event above can still reference the group (FKs then set it null).
  if del then delete from limit_groups where id = r.group_id; end if;
  return r;
end $$;

language plpgsql security definer set search_path = public as $$
begin

   where id = p_request_id and from_user = auth.uid() and status = 'granted' and applied_at is null;

create function public.log_event(p_kind text, p_group_id uuid default null,
                                 p_data jsonb default '{}'::jsonb, p_client_id text default null)
returns uuid language plpgsql security definer set search_path = public as $$
declare pid uuid := public.my_pair_id(); gid uuid := p_group_id; eid uuid;
begin
  if p_kind not in ('threshold_80', 'limit_reached', 'wildcard_used') then raise exception 'invalid_kind'; end if;
  if pid is null then return null; end if;
  -- The group may have been deleted while the event sat in the device outbox.
  if gid is not null and not exists (select 1 from limit_groups where id = gid and owner = auth.uid()) then

  values (pid, auth.uid(), p_kind, gid, coalesce(p_data, '{}'::jsonb), p_client_id)
  on conflict (client_id) do nothing
  returning id into eid;
  return eid;
end $$;

export interface Proposed {
  name?: string; app_count?: number; daily_minutes?: number | null;
  window_start?: number | null; window_end?: number | null; delete?: boolean;
}
export interface RequestRow {
  id: string; kind: Kind; status: "pending" | "granted" | "denied" | "superseded";
  minutes: number | null; granted_minutes: number | null; message: string | null;
  payload: Proposed | null; from_user: string; group_id: string | null;

export interface GroupRow {
  name: string; app_count: number; daily_minutes: number | null;
  window_start: number | null; window_end: number | null;

export interface EventRow { id: string; kind: string; actor: string; group_id: string | null; data: Record<string, unknown> }
export interface ApnsPayload {
  aps: { alert: { title: string; body: string }; sound: "default"; category?: string; "content-available"?: 1 };
  type: "request" | "granted" | "answered" | "event";
  request_id?: string;
  event_id?: string;

export function clock(m: number): string {
  return `${String(Math.floor(m / 60)).padStart(2, "0")}:${String(m % 60).padStart(2, "0")}`;
}
const windowText = (s: number | null, e: number | null) => (s === null || e === null ? "sin horario" : `${clock(s)}–${clock(e)}`);
const minutesText = (n: number | null) => (n === null ? "sin límite" : `${n} min`);

export function describeLoosen(current: GroupRow, p: Proposed): string {
  if (p.delete) return `Borrar el grupo ${current.name}`;
  const parts: string[] = [];
  const newMin = p.daily_minutes ?? null;
  if (newMin !== current.daily_minutes) parts.push(`${minutesText(current.daily_minutes)} → ${minutesText(newMin)}`);
  const ns = p.window_start ?? null, ne = p.window_end ?? null;
  if (ns !== current.window_start || ne !== current.window_end) {
    parts.push(`bloqueo ${windowText(current.window_start, current.window_end)} → ${windowText(ns, ne)}`);
  }
  if (p.app_count !== undefined && p.app_count !== current.app_count) parts.push(`${current.app_count} → ${p.app_count} apps`);
  if (parts.length === 0) parts.push("cambia qué apps entran");
  return `${current.name}: ${parts.join(" · ")}`;
}

export function pendingRequestPayload(r: RequestRow, group: GroupRow | null, fromName: string): ApnsPayload {
  const groupName = group?.name ?? "un grupo";
  if (r.kind === "extra_time") {
    return {
      aps: {
        alert: { title: `${fromName} pide ${r.minutes} min`, body: r.message ? `${groupName}: “${r.message}”` : groupName },
        sound: "default",
        category: `EXTRA_TIME_REQUEST_${r.minutes}`,
      },
      type: "request",
      request_id: r.id,
    };
  }
  return {
    aps: {
      alert: { title: `${fromName} quiere aflojar un límite`, body: group && r.payload ? describeLoosen(group, r.payload) : groupName },
      sound: "default",
      category: "LOOSEN_REQUEST",
    },
    type: "request",
    request_id: r.id,
  };
}

export function answeredRequestPayload(r: RequestRow, groupName: string | null, partnerName: string): ApnsPayload | null {
  if (r.status === "pending" || r.status === "superseded") return null;
  const g = groupName ?? "tu grupo";
  if (r.status === "denied") {
    const body = r.kind === "extra_time" ? `Sin minutos extra en ${g}` : `Sigue el límite actual de ${g}`;
    return { aps: { alert: { title: `${partnerName} dijo que no`, body }, sound: "default" }, type: "answered", request_id: r.id };
  }
  const title = r.kind === "extra_time" ? `Te dieron ${r.granted_minutes} min` : `${partnerName} aprobó tu cambio`;
  const body = r.kind === "extra_time" ? `${partnerName} te dio tiempo en ${g}` : g;
  return { aps: { alert: { title, body }, sound: "default", "content-available": 1 }, type: "granted", request_id: r.id };
}

  limit_reached: (a, g) => ({ title: `${a} llegó al límite`, body: g }),
  wildcard_used: (a, g) => ({ title: `${a} usó su comodín`, body: `5 min en ${g}` }),
  auth_revoked: (a) => ({ title: `${a} desactivó los permisos de Screen`, body: "Sus límites dejaron de aplicarse" }),
  silent_24h: (a) => ({ title: `${a} no reporta hace un día`, body: "Puede haber borrado la app o tener el celu apagado" }),
};

export function eventPayload(ev: EventRow, actorName: string, groupName: string | null): ApnsPayload | null {
  const f = EVENT_PUSH[ev.kind];
  if (!f) return null;
  return { aps: { alert: f(actorName, groupName ?? "un grupo"), sound: "default" }, type: "event", event_id: ev.id };
}

import { importPKCS8, SignJWT } from "npm:jose@6.2.12";
import type { ApnsPayload } from "./payloads.ts";

let cached: { jwt: string; at: number } | null = null;

// APNs provider tokens are valid for an hour; refresh a bit earlier.
async function providerToken(): Promise<string> {
  if (cached && Date.now() - cached.at < 50 * 60 * 1000) return cached.jwt;
  const key = await importPKCS8(Deno.env.get("APNS_KEY_P8")!.replace(/\\n/g, "\n"), "ES256");
  const jwt = await new SignJWT({})
    .setProtectedHeader({ alg: "ES256", kid: Deno.env.get("APNS_KEY_ID")! })
    .setIssuer(Deno.env.get("APNS_TEAM_ID")!)
    .setIssuedAt()
    .sign(key);
  cached = { jwt, at: Date.now() };
  return jwt;
}

export async function sendPush(deviceToken: string, payload: ApnsPayload): Promise<{ ok: boolean; status: number; reason?: string }> {
  const host = Deno.env.get("APNS_HOST") ?? "api.sandbox.push.apple.com";
  const res = await fetch(`https://${host}/3/device/${deviceToken}`, {
    method: "POST",
    headers: {
      authorization: `bearer ${await providerToken()}`,
      "apns-topic": Deno.env.get("APNS_TOPIC") ?? "com.facufuensa.screen",
      "apns-push-type": "alert",
      "apns-priority": "10",
      "content-type": "application/json",
    },
    body: JSON.stringify(payload),
  });
  if (res.ok) return { ok: true, status: res.status };
  const body = await res.json().catch(() => ({}));
  return { ok: false, status: res.status, reason: (body as { reason?: string }).reason };
}

import type { SupabaseClient } from "npm:@supabase/supabase-js@2.117.3";
import { sendPush } from "./apns.ts";
import {
  answeredRequestPayload, type ApnsPayload, eventPayload, type EventRow, type GroupRow,
  pendingRequestPayload, type RequestRow,
} from "./payloads.ts";

export type Result = { sent: boolean; reason?: string };
type Pair = { id: string; user_a: string; user_b: string };

async function pairOf(admin: SupabaseClient, id: string): Promise<Pair> {
  const { data, error } = await admin.from("pairs").select("id,user_a,user_b").eq("id", id).single();
  if (error) throw error;
  return data as Pair;
}
async function nameOf(admin: SupabaseClient, id: string): Promise<string> {
  const { data } = await admin.from("profiles").select("display_name").eq("id", id).single();
  return (data as { display_name: string } | null)?.display_name ?? "Tu pareja";
}
async function groupOf(admin: SupabaseClient, id: string | null): Promise<GroupRow | null> {
  if (!id) return null;
  const { data } = await admin.from("limit_groups")
    .select("name,app_count,daily_minutes,window_start,window_end").eq("id", id).maybeSingle();
  return data as GroupRow | null;
}
const other = (p: Pair, u: string) => (u === p.user_a ? p.user_b : p.user_a);
const isMember = (p: Pair, u: string) => u === p.user_a || u === p.user_b;

async function push(admin: SupabaseClient, to: string, payload: ApnsPayload | null): Promise<Result> {
  if (!payload) return { sent: false, reason: "nothing_to_send" };
  const { data } = await admin.from("profiles").select("apns_token").eq("id", to).single();
  const token = (data as { apns_token: string | null } | null)?.apns_token;
  if (!token) return { sent: false, reason: "no_token" };
  const res = await sendPush(token, payload);
  if (res.status === 410 || res.reason === "BadDeviceToken") {
    await admin.from("profiles").update({ apns_token: null }).eq("id", to);
  }
  return { sent: res.ok, reason: res.reason };
}

export async function deliverRequest(admin: SupabaseClient, requestId: string, callerId: string): Promise<Result> {
  const { data, error } = await admin.from("requests").select("*").eq("id", requestId).maybeSingle();
  if (error || !data) return { sent: false, reason: "not_found" };
  const r = data as RequestRow & { pair_id: string };
  const pair = await pairOf(admin, r.pair_id);
  if (!isMember(pair, callerId)) return { sent: false, reason: "forbidden" };
  const partner = other(pair, r.from_user);
  const group = await groupOf(admin, r.group_id);
  if (r.status === "pending") {
    return push(admin, partner, pendingRequestPayload(r, group, await nameOf(admin, r.from_user)));
  }
  return push(admin, r.from_user, answeredRequestPayload(r, group?.name ?? null, await nameOf(admin, partner)));
}

export async function deliverEvent(admin: SupabaseClient, eventId: string, callerId: string | null): Promise<Result> {
  const { data, error } = await admin.from("events").select("*").eq("id", eventId).maybeSingle();
  if (error || !data) return { sent: false, reason: "not_found" };
  const ev = data as EventRow & { pair_id: string };
  const pair = await pairOf(admin, ev.pair_id);
  if (callerId && !isMember(pair, callerId)) return { sent: false, reason: "forbidden" };
  const group = await groupOf(admin, ev.group_id);
  return push(admin, other(pair, ev.actor), eventPayload(ev, await nameOf(admin, ev.actor), group?.name ?? null));
}

/// JSON values in the App Group defaults, readable by the app and every extension.
struct SharedStore {
    var defaults: UserDefaults = AppGroup.defaults

    func load<T: Decodable>(_ type: T.Type, key: String) -> T? {
        guard let data = defaults.data(forKey: key) else { return nil }
        return try? JSONDecoder().decode(T.self, from: data)
    }

    func save<T: Encodable>(_ value: T, key: String) {
        if let data = try? JSONEncoder().encode(value) { defaults.set(data, forKey: key) }
    }

    func remove(_ key: String) { defaults.removeObject(forKey: key) }
}

struct OutboxItem: Codable, Equatable {
    let clientID: String
    let kind: String
    let groupID: UUID?
    let createdAt: Date

/// Extensions have no reliable network, so device events wait here until the
/// app uploads them. Client IDs are deterministic per kind, group and day, so a
/// re-fired threshold never shows up twice in the partner's feed.
struct Outbox {
    var store = SharedStore()

    func enqueue(kind: String, groupID: UUID?, now: Date = .now) {
        let id = "\(kind).\(groupID?.uuidString ?? "-").\(DayKey.string(for: now))"
        var items = all()
        guard !items.contains(where: { $0.clientID == id }) else { return }
        items.append(OutboxItem(clientID: id, kind: kind, groupID: groupID, createdAt: now))
        store.save(items, key: SharedKey.outbox)
    }

    func all() -> [OutboxItem] { store.load([OutboxItem].self, key: SharedKey.outbox) ?? [] }

    func remove(clientIDs: Set<String>) {
        store.save(all().filter { !clientIDs.contains($0.clientID) }, key: SharedKey.outbox)
    }
}

import DeviceActivity
import FamilyControls
import Foundation
import ManagedSettings
import ScreenCore

enum ActivityName {
    static func daily(_ id: UUID) -> DeviceActivityName { .init("daily.\(id.uuidString)") }
    static func window(_ id: UUID, _ index: Int) -> DeviceActivityName { .init("window.\(id.uuidString).\(index)") }
    static func extra(_ id: UUID) -> DeviceActivityName { .init("extra.\(id.uuidString)") }

    static func parse(_ name: DeviceActivityName) -> (kind: String, groupID: UUID, index: Int?)? {
        let parts = name.rawValue.split(separator: ".").map(String.init)
        guard parts.count >= 2, let id = UUID(uuidString: parts[1]) else { return nil }
        return (parts[0], id, parts.count > 2 ? Int(parts[2]) : nil)
    }
}

extension DeviceActivityEvent.Name {
    static let limit = Self("limit")
    static let warn = Self("warn80")
    static let used = Self("used")
}

/// The only place that touches DeviceActivity and ManagedSettings. Each group
/// owns up to four activities (daily, two window segments, extra time) and one
/// named ManagedSettingsStore; whether it is shielded is GroupRuntime.shouldShield.
final class Enforcer {
    let store: SharedStore
    let center = DeviceActivityCenter()
    var calendar = Calendar.current

    init(store: SharedStore = SharedStore()) { self.store = store }

    var groups: [LimitGroup] { store.load([LimitGroup].self, key: SharedKey.groups) ?? [] }
    func group(_ id: UUID) -> LimitGroup? { groups.first { $0.id == id } }

    func ledger(now: Date) -> DayLedger {
        let today = DayKey.string(for: now, calendar: calendar)
        var l = store.load(DayLedger.self, key: SharedKey.ledger) ?? DayLedger(day: today)
        l.roll(to: today)
        return l
    }

    private func save(_ l: DayLedger) { store.save(l, key: SharedKey.ledger) }

    func updateRuntime(_ id: UUID, now: Date = .now, _ change: (inout GroupRuntime) -> Void) {
        var l = ledger(now: now)
        var rt = l.runtime[id.uuidString, default: GroupRuntime()]
        change(&rt)
        l.runtime[id.uuidString] = rt
        save(l)
        applyShield(id, runtime: rt)
    }

    /// Re-derives every group's shield, e.g. right after midnight.
    func refreshAll(now: Date = .now) {
        var l = ledger(now: now)
        let minute = DayKey.minuteOfDay(now, calendar: calendar)
        for g in groups {
            var rt = l.runtime[g.id.uuidString, default: GroupRuntime()]
            rt.inWindow = g.window?.contains(minute: minute) ?? false
            l.runtime[g.id.uuidString] = rt
        }
        save(l)
        for g in groups { applyShield(g.id, runtime: l.runtime[g.id.uuidString] ?? GroupRuntime()) }
    }

    func applyShield(_ id: UUID, runtime: GroupRuntime) {
        let s = ManagedSettingsStore(named: .init(id.uuidString))
        guard runtime.shouldShield, let g = group(id) else { s.clearAllSettings(); return }
        s.shield.applications = g.selection.applicationTokens.isEmpty ? nil : g.selection.applicationTokens
        s.shield.applicationCategories = g.selection.categoryTokens.isEmpty ? nil : .specific(g.selection.categoryTokens)
        s.shield.webDomains = g.selection.webDomainTokens.isEmpty ? nil : g.selection.webDomainTokens
    }

    /// Stores `new` and restarts monitoring for the groups that changed.
    func install(groups new: [LimitGroup], now: Date = .now) throws {
        let old = groups
        store.save(new, key: SharedKey.groups)
        for g in old where !new.contains(where: { $0.id == g.id }) {
            center.stopMonitoring(activities(for: g.id, includingExtra: true))
            ManagedSettingsStore(named: .init(g.id.uuidString)).clearAllSettings()
        }
        var l = ledger(now: now)
        let minute = DayKey.minuteOfDay(now, calendar: calendar)
        for g in new {
            let before = old.first { $0.id == g.id }
            guard before != g else { continue }
            center.stopMonitoring(activities(for: g.id, includingExtra: false))
            try startDaily(g)
            for (i, seg) in (g.window?.segments() ?? []).enumerated() {
                try center.startMonitoring(ActivityName.window(g.id, i), during: schedule(seg, repeats: true))
            }
            var rt = l.runtime[g.id.uuidString, default: GroupRuntime()]
            // A raised or removed limit clears today's block; a lowered one is
            // re-detected by the threshold event, which counts past usage.
            if let o = before?.dailyMinutes, g.dailyMinutes.map({ $0 > o }) ?? true { rt.limitReached = false }
            rt.inWindow = g.window?.contains(minute: minute) ?? false
            l.runtime[g.id.uuidString] = rt
        }
        save(l)
        for g in new { applyShield(g.id, runtime: l.runtime[g.id.uuidString] ?? GroupRuntime()) }
    }

    /// Unlocks the group for `minutes` of real use. Idempotent per request ID.
    @discardableResult
    func grantCredit(groupID: UUID, minutes: Int, requestID: String?, now: Date = .now) throws -> Bool {
        guard let g = group(groupID) else { return false }
        var l = ledger(now: now)
        if let r = requestID, l.hasApplied(r) { return false }
        let seg = UsageRules.extraTimeInterval(nowMinute: DayKey.minuteOfDay(now, calendar: calendar))
        center.stopMonitoring([ActivityName.extra(groupID)])
        try center.startMonitoring(ActivityName.extra(groupID), during: schedule(seg, repeats: false),
                                   events: [.used: event(g, minutes: minutes, includesPast: false)])
        if let r = requestID { l.markApplied(r) }
        var rt = l.runtime[groupID.uuidString, default: GroupRuntime()]
        rt.creditActive = true
        l.runtime[groupID.uuidString] = rt
        save(l)
        applyShield(groupID, runtime: rt)
        return true
    }

    /// 5 minutes once a day, no approval. The partner hears about it through the outbox.
    func useWildcard(groupID: UUID, now: Date = .now) throws -> Bool {
        guard ledger(now: now).canUseWildcard else { return false }
        guard try grantCredit(groupID: groupID, minutes: UsageRules.wildcardMinutes, requestID: nil, now: now) else { return false }
        var l = ledger(now: now)
        l.consumeWildcard()
        save(l)
        Outbox(store: store).enqueue(kind: "wildcard_used", groupID: groupID, now: now)
        return true
    }

    func endCredit(groupID: UUID, now: Date = .now) {
        center.stopMonitoring([ActivityName.extra(groupID)])
        updateRuntime(groupID, now: now) { $0.creditActive = false }
    }

    func groupID(containing token: ApplicationToken) -> UUID? {
        groups.first { $0.selection.applicationTokens.contains(token) }?.id
    }
    func groupID(containing token: ActivityCategoryToken) -> UUID? {
        groups.first { $0.selection.categoryTokens.contains(token) }?.id
    }
    func groupID(containing token: WebDomainToken) -> UUID? {
        groups.first { $0.selection.webDomainTokens.contains(token) }?.id
    }

    // MARK: - Private

    private func activities(for id: UUID, includingExtra: Bool) -> [DeviceActivityName] {
        var names = [ActivityName.daily(id), ActivityName.window(id, 0), ActivityName.window(id, 1)]
        if includingExtra { names.append(ActivityName.extra(id)) }
        return names
    }

    private func startDaily(_ g: LimitGroup) throws {
        var events: [DeviceActivityEvent.Name: DeviceActivityEvent] = [:]
        if let daily = g.dailyMinutes {
            events[.limit] = event(g, minutes: daily, includesPast: true)
            if let w = UsageRules.warnThreshold(daily: daily) { events[.warn] = event(g, minutes: w, includesPast: true) }
        }
        // Registered even without a daily limit: its intervalDidStart is the midnight tick.
        try center.startMonitoring(
            ActivityName.daily(g.id),
            during: DeviceActivitySchedule(intervalStart: DateComponents(hour: 0, minute: 0),
                                           intervalEnd: DateComponents(hour: 23, minute: 59), repeats: true),
            events: events)
    }

    private func event(_ g: LimitGroup, minutes: Int, includesPast: Bool) -> DeviceActivityEvent {
        DeviceActivityEvent(applications: g.selection.applicationTokens,
                            categories: g.selection.categoryTokens,
                            webDomains: g.selection.webDomainTokens,
                            threshold: DateComponents(minute: minutes),
                            includesPastActivity: includesPast)
    }

    private func schedule(_ seg: DaySegment, repeats: Bool) -> DeviceActivitySchedule {
        DeviceActivitySchedule(intervalStart: DateComponents(hour: seg.startMinute / 60, minute: seg.startMinute % 60),
                               intervalEnd: DateComponents(hour: seg.endMinute / 60, minute: seg.endMinute % 60),
                               repeats: repeats)
    }
}

import DeviceActivity
import Foundation

final class ScreenMonitor: DeviceActivityMonitor {
    private let enforcer = Enforcer()

    override func intervalDidStart(for activity: DeviceActivityName) {
        super.intervalDidStart(for: activity)
        guard let a = ActivityName.parse(activity) else { return }
        switch a.kind {
        case "daily": enforcer.refreshAll()  // midnight: the ledger rolls inside refreshAll
        case "window": enforcer.updateRuntime(a.groupID) { $0.inWindow = true }
        default: break
        }
    }

    override func intervalDidEnd(for activity: DeviceActivityName) {
        super.intervalDidEnd(for: activity)
        guard let a = ActivityName.parse(activity) else { return }
        switch a.kind {
        case "window":
            // The 23:59 end of an overnight window is not the end of the block.
            let segments = enforcer.group(a.groupID)?.window?.segments() ?? []
            if let i = a.index, segments.indices.contains(i), segments[i].continuesNextDay { return }
            enforcer.updateRuntime(a.groupID) { $0.inWindow = false }
        case "extra":
            enforcer.endCredit(groupID: a.groupID)
        default: break
        }
    }

    override func eventDidReachThreshold(_ event: DeviceActivityEvent.Name, activity: DeviceActivityName) {
        super.eventDidReachThreshold(event, activity: activity)
        guard let a = ActivityName.parse(activity) else { return }
        switch (a.kind, event) {
        case ("daily", .limit):
            enforcer.updateRuntime(a.groupID) { $0.limitReached = true }
            Outbox().enqueue(kind: "limit_reached", groupID: a.groupID)
        case ("daily", .warn):
            Outbox().enqueue(kind: "threshold_80", groupID: a.groupID)
        case ("extra", .used):
            enforcer.endCredit(groupID: a.groupID)
        default: break
        }
    }
}

/// A loosening waiting for the partner. Kept on device because only this phone

struct PendingEdit: Codable, Equatable {

    var delete: Bool

struct PendingEdits {
    var store = SharedStore()

    func all() -> [String: PendingEdit] { store.load([String: PendingEdit].self, key: SharedKey.pendingEdits) ?? [:] }

    func set(_ edit: PendingEdit) {
        var map = all()
        map[edit.group.id.uuidString] = edit
        store.save(map, key: SharedKey.pendingEdits)
    }

    func take(groupID: UUID) -> PendingEdit? {
        var map = all()
        let edit = map.removeValue(forKey: groupID.uuidString)
        store.save(map, key: SharedKey.pendingEdits)
        return edit
    }
}

import Foundation
import ScreenCore

@MainActor
final class GroupsModel: ObservableObject {
    enum Outcome { case applied, sentForApproval }

    @Published private(set) var groups: [LimitGroup] = []
    @Published private(set) var pending: [String: PendingEdit] = [:]
    @Published private(set) var partnerGroups: [GroupRow] = []

    let enforcer = Enforcer()
    let backend = Backend.shared

    func reload() {
        groups = enforcer.groups
        pending = PendingEdits().all()
    }

    func loadRemote(partnerID: UUID?) async {
        guard let partnerID, let rows = try? await backend.remoteGroups() else { return }
        partnerGroups = rows.filter { $0.owner == partnerID }
    }

    func save(_ edited: LimitGroup, paired: Bool) async throws -> Outcome {
        let old = groups.first { $0.id == edited.id }
        let verdict = old.map { LimitChange.classify(from: $0.config, to: edited.config) } ?? .tightening
        let removesApps = old.map { LimitChange.removesApps(from: $0.config, to: edited.config) } ?? false

        if verdict == .loosening && paired {
            PendingEdits().set(PendingEdit(group: edited, delete: false))
            let id = try await backend.requestLoosen(groupID: edited.id, payload: LoosenPayload(edited), message: nil)
            await backend.notify(requestID: id)
            reload()
            return .sentForApproval
        }

        // Tightening never waits for the network.
        var next = groups
        if let i = next.firstIndex(where: { $0.id == edited.id }) { next[i] = edited } else { next.append(edited) }
        try enforcer.install(groups: next)
        reload()
        // The mirror catches up on the next sync if this fails.
        _ = try? await backend.saveGroup(edited, removesApps: removesApps)
        return .applied
    }

    func delete(_ group: LimitGroup, paired: Bool) async throws -> Outcome {
        if paired {
            PendingEdits().set(PendingEdit(group: group, delete: true))
            let id = try await backend.requestLoosen(groupID: group.id, payload: LoosenPayload(group, delete: true), message: nil)
            await backend.notify(requestID: id)
            reload()
            return .sentForApproval
        }
        try enforcer.install(groups: groups.filter { $0.id != group.id })
        reload()
        try? await backend.deleteGroup(group.id)
        return .applied
    }
}

extension AuthorizationStatus {

        @unknown default: return "unknown"

/// Everything that needs the network and might have been missed: runs on every
/// foreground, background refresh and push. Each step is safe to repeat.
@MainActor
final class SyncService {
    static let shared = SyncService()
    private let backend = Backend.shared
    private let enforcer = Enforcer()
    private var running = false

    func run() async {
        guard !running, await backend.currentUserID() != nil else { return }
        running = true; defer { running = false }

        let status = AuthorizationCenter.shared.authorizationStatus.wireValue
        if let eid = try? await backend.heartbeat(authStatus: status, apnsToken: PushToken.current) {
            await backend.notify(eventID: eid)
        }
        await flushOutbox()
        await applyGrants()
        // Re-mirror local groups; the server rejects anything looser, which is fine.
        for g in enforcer.groups { _ = try? await backend.saveGroup(g, removesApps: false) }
    }

    private func flushOutbox() async {
        let outbox = Outbox()
        var sent = Set<String>()
        for item in outbox.all() {
            do {
                if let id = try await backend.logEvent(item) { await backend.notify(eventID: id) }
                sent.insert(item.clientID)
            } catch {
                break  // offline: try again next time
            }
        }
        outbox.remove(clientIDs: sent)
    }

    private func applyGrants() async {
        guard let grants = try? await backend.myUnappliedGrants() else { return }
        let today = DayKey.string(for: .now)
        for r in grants {
            switch r.kind {
            case .extraTime:
                // Yesterday's minutes are gone; just acknowledge them.
                if let answered = r.answeredAt, DayKey.string(for: answered) == today,
                   let gid = r.groupID, let minutes = r.grantedMinutes {
                    _ = try? enforcer.grantCredit(groupID: gid, minutes: minutes, requestID: r.id.uuidString)
                }
            case .loosenLimit:
                if let gid = r.groupID ?? pendingGroupID(for: r) { applyApprovedEdit(groupID: gid, request: r) }
            }
            try? await backend.markApplied(r.id)
        }
    }

    /// A deleted group comes back with group_id null; find it among the pending edits.
    private func pendingGroupID(for r: RequestRow) -> UUID? {
        guard r.payload?.delete == true else { return nil }
        return PendingEdits().all().values.first(where: { $0.delete })?.group.id
    }

    private func applyApprovedEdit(groupID: UUID, request r: RequestRow) {
        var groups = enforcer.groups
        if let edit = PendingEdits().take(groupID: groupID) {
            if edit.delete {
                groups.removeAll { $0.id == groupID }
            } else if let i = groups.firstIndex(where: { $0.id == groupID }) {
                groups[i] = edit.group
            }
        } else if let p = r.payload, let i = groups.firstIndex(where: { $0.id == groupID }) {
            // App reinstalled: no local edit, so apply the numbers and keep the apps.
            if p.delete == true {
                groups.remove(at: i)
            } else {
                groups[i].dailyMinutes = p.dailyMinutes
                groups[i].window = p.windowStart.flatMap { s in p.windowEnd.map { BlockWindow(startMinute: s, endMinute: $0) } }
            }
        }
        try? enforcer.install(groups: groups)
    }
}

        }

@MainActor
enum NotificationRouter {
    static func handle(_ response: UNNotificationResponse) async {
        let info = response.notification.request.content.userInfo
        let type = info["type"] as? String

        if type == "ask" {
            Router.shared.sheet = .ask((info["group_id"] as? String).flatMap(UUID.init))
            return
        }
        guard let rid = (info["request_id"] as? String).flatMap(UUID.init) else {
            await SyncService.shared.run()
            return
        }
        switch response.actionIdentifier {
        case "GRANT", "APPROVE": await answer(rid, grant: true)
        case "DENY": await answer(rid, grant: false)
        case "GRANT_OTHER": Router.shared.sheet = .answer(rid)
        default:
            if type == "request" { Router.shared.tab = .requests } else { await SyncService.shared.run() }
        }
    }

    private static func answer(_ rid: UUID, grant: Bool) async {
        do {
            try await Backend.shared.answer(requestID: rid, grant: grant, minutes: nil)
            await Backend.shared.notify(requestID: rid)
        } catch {
            // Answered from the lock screen, so say why it did nothing.
            let c = UNMutableNotificationContent()
            c.title = "No se pudo responder"
            c.body = error.localizedDescription
            try? await UNUserNotificationCenter.current().add(UNNotificationRequest(identifier: UUID().uuidString, content: c, trigger: nil))
        }
    }

```yaml
name: Device build (development)
on:
  workflow_dispatch:
    inputs:
      base_url:
        description: "HTTPS base URL where ota/ will be served (e.g. https://screen-ota.vercel.app)"
        required: true
jobs:
  build:
    runs-on: macos-26
    timeout-minutes: 45
    steps:
      - uses: actions/checkout@v4
      - name: Check secrets
        env:
          ASC_KEY_ID: ${{ secrets.ASC_KEY_ID }}
          ASC_ISSUER_ID: ${{ secrets.ASC_ISSUER_ID }}
          ASC_KEY_P8: ${{ secrets.ASC_KEY_P8 }}
          SUPABASE_URL: ${{ secrets.SUPABASE_URL }}
          SUPABASE_ANON_KEY: ${{ secrets.SUPABASE_ANON_KEY }}
        run: |
          missing=0
          for v in ASC_KEY_ID ASC_ISSUER_ID ASC_KEY_P8 SUPABASE_URL SUPABASE_ANON_KEY; do
            if [ -z "${!v}" ]; then echo "::error::Missing secret $v"; missing=1; fi
          done
          exit $missing
      - run: brew install xcodegen && xcodegen generate
      - name: Write API key
        env:
          ASC_KEY_P8: ${{ secrets.ASC_KEY_P8 }}
        run: mkdir -p private && printf '%s\n' "$ASC_KEY_P8" > private/AuthKey.p8
      - name: Archive
        env:
          ASC_KEY_ID: ${{ secrets.ASC_KEY_ID }}
          ASC_ISSUER_ID: ${{ secrets.ASC_ISSUER_ID }}
          SUPABASE_URL: ${{ secrets.SUPABASE_URL }}
          SUPABASE_ANON_KEY: ${{ secrets.SUPABASE_ANON_KEY }}
        run: |
          set -o pipefail
          # xcodebuild echoes its argv; redact before anything reaches a file.
          redact () { sed -e "s|$SUPABASE_ANON_KEY|<redacted>|g"; }
          xcodebuild archive -project Screen.xcodeproj -scheme Screen -configuration Debug \
            -destination 'generic/platform=iOS' -archivePath build/Screen.xcarchive \
            -allowProvisioningUpdates \
            -authenticationKeyPath "$PWD/private/AuthKey.p8" \
            -authenticationKeyID "$ASC_KEY_ID" -authenticationKeyIssuerID "$ASC_ISSUER_ID" \
            CURRENT_PROJECT_VERSION="${{ github.run_number }}" \
            SUPABASE_URL="$SUPABASE_URL" SUPABASE_ANON_KEY="$SUPABASE_ANON_KEY" \
            2>&1 | redact | tee archive.log | tail -n 100
      - name: Export
        env:
          ASC_KEY_ID: ${{ secrets.ASC_KEY_ID }}
          ASC_ISSUER_ID: ${{ secrets.ASC_ISSUER_ID }}
        run: |
          set -o pipefail
          xcodebuild -exportArchive -archivePath build/Screen.xcarchive \
            -exportOptionsPlist ci/exportOptions-debugging.plist -exportPath build/export \
            -allowProvisioningUpdates \
            -authenticationKeyPath "$PWD/private/AuthKey.p8" \
            -authenticationKeyID "$ASC_KEY_ID" -authenticationKeyIssuerID "$ASC_ISSUER_ID" \
            2>&1 | tee export.log | tail -n 60
      - name: Build OTA folder
        run: |
          BASE="${{ inputs.base_url }}"
          mkdir -p ota
          cp build/export/Screen.ipa ota/Screen.ipa
          cat > ota/manifest.plist <<EOF
          <?xml version="1.0" encoding="UTF-8"?>
          <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
          <plist version="1.0"><dict><key>items</key><array><dict>
            <key>assets</key><array><dict><key>kind</key><string>software-package</string><key>url</key><string>$BASE/Screen.ipa</string></dict></array>
            <key>metadata</key><dict><key>bundle-identifier</key><string>com.facufuensa.screen</string><key>bundle-version</key><string>${{ github.run_number }}</string><key>kind</key><string>software</string><key>title</key><string>Screen</string></dict>
          </dict></array></dict></plist>
          EOF
          cat > ota/index.html <<EOF
          <!doctype html><meta name="viewport" content="width=device-width">
          <a style="font:600 22px -apple-system;display:block;margin:40px 16px" href="itms-services://?action=download-manifest&url=$BASE/manifest.plist">Instalar Screen (build ${{ github.run_number }})</a>
          EOF
      - uses: actions/upload-artifact@v4
        with:
          name: ota
          path: ota/
      - name: Upload logs on failure
        if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: xcodebuild-logs
          path: |
            archive.log
            export.log
          if-no-files-found: ignore
```

`docs/QA.md`:
```markdown
# QA manual — Screen v1 (dos iPhone reales, A y B)

Family Controls no funciona en el simulador: todo esto es en dispositivo.

## Arranque
- [ ] A y B crean cuenta, dan los dos permisos y se emparejan con el código.
- [ ] La pantalla de emparejar de A avanza sola cuando B usa el código.

## Límite diario
- [ ] A crea "Redes" (TikTok, Instagram), 5 min por día. B lo ve en "Límites de A".
- [ ] A usa TikTok 4 min → B ve "usó el 80 %" en Actividad (puede tardar hasta que A abra la app).
- [ ] A llega a 5 min → aparece la pantalla de bloqueo "Se terminó tu tiempo de hoy en Redes". B recibe push "A llegó al límite".

## Pedido de tiempo
- [ ] En el bloqueo, A toca "Pedir tiempo" → notificación → abre la app con Redes elegido.
- [ ] A pide 5 min con mensaje → B recibe "A pide 5 min" con "Dar 5 min / Otra cantidad / No".
- [ ] B toca "Dar 5 min" desde la notificación, sin abrir la app → A recibe "Te dieron 5 min" y TikTok se desbloquea.
- [ ] Después de 5 min de uso real, TikTok se vuelve a bloquear.
- [ ] Con la app de A cerrada a la fuerza: B aprueba → A abre la app → se desbloquea (sync al abrir), una sola vez.
- [ ] B elige "Otra cantidad", da 12 → A recibe 12 min.
- [ ] Un pedido sin respuesta durante 30 min aparece como "Venció sin respuesta"; aprobarlo después muestra "El pedido ya venció".

## Comodín
- [ ] En el bloqueo, "Usar comodín (5 min)" desbloquea al instante, incluso en modo avión.
- [ ] Al volver la red, B ve "A usó su comodín". El botón no vuelve a aparecer hasta mañana.

## Aflojar y endurecer
- [ ] A baja Redes a 3 min → se aplica al instante; B ve "endureció un límite".
- [ ] A sube a 30 min → aviso "Le mandamos el cambio a B"; sigue valiendo 3 min.
- [ ] B ve "3 min → 30 min" y aprueba → en A queda 30 min.
- [ ] A cambia Instagram por Notas (mismo número de apps) → se pide aprobación.
- [ ] A intenta borrar el grupo → se pide aprobación.

## Horario de bloqueo
- [ ] A pone bloqueo 23:00–07:00 (o una franja cercana para probar) → en la franja se bloquea solo.
- [ ] Una franja que cruza medianoche no desbloquea a las 23:59 (probar con 23:30–00:30).
- [ ] Un pedido aprobado durante la franja desbloquea por los minutos dados.

## Trampas
- [ ] A le quita el permiso a Screen en Ajustes y abre la app → B recibe "A desactivó los permisos de Screen".
- [ ] A borra la app → a las ~24 h B recibe "A no reporta hace un día".
```
